# 研究图示的表达原则

这些文字经验来自实际制图和案例讨论。按当前论文与图的用途采用，不作为固定模板；研究方法、数字和结果始终以当前论文为依据。公开版本不包含个人参考截图或历史成图。

## 用结构分担文字

- 数据、关系探索与策略推演可有不同任务和视觉份量；小型路径图可表达构念关系。公式、阈值与情景设计只有在帮助理解研究定义时才进入图面。
- 同一上游的独立分析应并行；多尺度模型可以并列。前一步形成指标矩阵，后一步应明确接收该矩阵，不能只靠相邻摆放暗示交接。
- 同一对象的输入、模拟输出与分类结果可融入具体方法。对照保持可比的视角、尺度和标签；模拟与实测身份明确。长提示词通常放在配套说明。

## 让图片参与步骤

输入样本放在数据或对象环节；方法中间状态放在对应转换处；解释曲线放在模型解释环节；分区地图放在聚类输出环节。图片与短标签共同说明输入、处理或输出，不默认另设一列原图。

真实论文图的图例、单位、比例尺和比较条件必须保留。缩览时必要细节难辨认，应选择语义完整的相关面板、扩大关键局部或减少重复文字，不能只依赖放大查看。

## 避免从案例继承版式

不继承固定配色、栏数、方形画布、字号数值、每框一个图标或等大模块。最多三级视觉层级与三档字号是样式约束，不能替代信息取舍和目标展示尺寸下的整图检查。

新任务不沿用旧研究的照片、标志、方法和数字。少量通用图标的来源与许可见 `../icons/`；用户提供的参考素材单独记录来源和使用范围。
