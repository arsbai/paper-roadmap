# Innovation 式科研图解

本技能默认借鉴 The Innovation / The Innovation Geoscience 的图解表达。目标是让研究对象、方法转换与主要产物能被直接看懂，成图接近可用于论文的 graphical framework。默认输出英文；中文材料和中文交流不改变该默认值。用户的明确语言、风格、版式及内容锁定要求优先。

## 选参考，也选研究关系

先从 [参考索引](../assets/innovation/index.md) 选 2—3 张：多源输入选观测/数据融合类，平行研究选分区/并列类，有真实反馈才选闭环类。实际打开图片，判断可借鉴的图文比例、主体位置、标题带、路径与留白。十张参考是不同表达可能性，不是十个固定模板。

学习视觉组织，不移植科学内容。参考里有四步、新模型、环形箭头或重要需求框，都不代表当前论文也应有。没有来源支持的步骤、数值、地图和反馈不能为了像参考而添加。参考中拥挤的小字、过重的渐变或装饰也不必继承。

## 形成视觉主线

- **主角明确。** 把研究对象、关键转换或创新产物做成视觉主体。例如仪器/样本的处理变化、跨期图像比较、空间场景、多模态模型的信息交接。图形承担解释，不是给文字卡片逐一配图标。
- **分区有任务。** 用浅色底、细边界或留白区分研究任务，用清晰标题带建立阅读入口。编号或字母只在有助于定位时使用，不能用数字掩盖并行关系；模块面积随内容重要性变化。
- **插画与原图共用。** 概念场景、矢量对象和动作图标可以说明过程；实测照片、地图与结果图说明真实对象或产物。图片应属于某个研究环节，而不是旁列装饰相册。自绘图若有数据/地图外观，标明 Schematic / Conceptual。
- **短标签配转换。** 英文标题用简洁名词短语，说明用必要的动作或条件。保留类别、方法、组别、时间、单位、重要筛选及适用范围；完整参数表、长提示词和常规软件操作放到配套说明。
- **色与线统一。** 淡底色支撑分区，较明确的同系色用于标题、图标及关系；可用轻渐变标题带和短而完整的渐变箭头。避免让浓重背景、阴影、彩色小框和粗线争夺主体。最多三级视觉层级和三档字号，具体数值按目标版面选择。

科学关系优先于视觉气势。串联用有方向的交接，平行研究用分叉/分组，类别用并列。需要表达“综合提供科学依据”时，从共同研究分组引出，不能只从最后一个子项发出；未经验证的关系保持关联或假设措辞。只有原文确有反馈过程时才画环，不为模仿期刊图而加装饰闭环。

## 英文布局

从同一份内容记录生成英文标签，必要时按英文长度重排模块和换行。首次生成不附带未请求的中文版。编号标题、类别和边标签与正文使用同一套三档字号，不为塞字增加第四档或不断缩小文字。

英文的长词、复数、连字符、冠词和术语要人工核对。确保同一概念用词一致、单词不因 tspan 换行粘连。原始图片里的必要图例/单位可保留来源语言，外围解释用英文，不擅自改造真实图中的数值。

## 两轮对比与优化

首次制图和整体重绘按下面执行；局部追改保持认可版本的其余内容与风格。

1. **第一轮：形成结构后比较。** 实际渲染初稿；在合理的整图展示宽度下，把初稿与已选参考图共同查看。比较视觉主体是否突出、是否仍为文字列表拼接、插画能否解释方法、原图是否融入步骤、模块份量和留白是否合适。写出具体发现并落实有依据的修改；科学关系不因美化改变。
2. **第二轮：修订后再比较。** 将修订稿再次与相同或更合适的参考图共同查看，检查第一轮改动、色彩层级、文字/图形比例和跨模块路径。补齐剩余问题后，实际查看最终整图与密集局部。

特别检查：跨期/配对图像是否共同进入比较方法；宽箭头是否被后绘面板遮住；箭头尖是否误指某个类别而非整体分组；连接是否穿过文字；图标是否盖住主体；主体场景是否压住标签；未来工具是否被接成既有研究数据来源。它们是实际使用中出现过的误读风险，不是每图都要增加的节点。

记录用任务大小即可，例如：

```json
{
  "references": ["assets/innovation/01-...jpg", "assets/innovation/02-...jpg"],
  "rounds": [
    {"draft":"draft-1.png","width":1800,"findings":["..."],"changes":["..."]},
    {"draft":"draft-2.png","width":1800,"findings":["..."],"changes":["..."]}
  ],
  "final_inspection": ["whole figure", "dense region"],
  "remaining_limitations": []
}
```

只有实际完成的查看才记录为完成。第二轮没有实质问题时记录依据，不强行制造修改。浏览器几何检查不能替代看图；可用现有离线渲染器后实际检查，但应如实说明工具覆盖范围。

## 参考图的边界

参考库中的期刊图用于视觉学习，并保留独立许可、作者、文章、DOI、图号、来源链接和图像处理记录。它们不因随本技能分发而变为 MIT 内容，也不表示期刊背书。生成新图通常应重新绘制适合当前研究的对象与连接；若确实需要复用第三方原图，按其具体许可保留归属与改动说明，并确认图内另行标注的第三方材料。
