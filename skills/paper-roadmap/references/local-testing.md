# 本地测试场景

创建时的结构校验与辅助脚本测试不等于真实论文端到端试用。用下列场景观察技能是否真正复用；只记录实际完成的场景。

| 场景 | 提供材料与请求 | 可观察的通过条件 |
|---|---|---|
| 默认英文 | 用中文提出制图请求，未指定成图语言 | 默认交付英文 SVG 和预览；不因交流或材料是中文而生成中文版 |
| 指定语言覆盖默认 | 明确要求中文、其他语言或中英双语 | 按指定语言交付；默认英文不覆盖明确要求 |
| 默认 Innovation 风格 | 中文请求、未指定语言和风格的新图；材料包含多源输入、一个创新方法及并列输出 | 输出英文；实际查看选定参考图；用对象/方法图解承担解释，浅色任务分区与标题层级清楚，不硬套四宫格或闭环 |
| 两轮视觉对比 | 新图或整体重绘完成初稿 | 实际将初稿和修订稿各与参考图共同查看，记录每轮发现与落实的优化，最后查整图和密集局部；不以渲染两次冒充两轮比较 |
| 真实关系覆盖风格 | 同一上游产生两个独立分析，另有未来调研工具 | 两分析并列，工具保留未来状态；参考图中的环形箭头、编号及场景不造成伪因果或已闭合验证 |
| 新实验论文 | 一篇含处理组、对照组及多时间点的论文，要求中文技术路线图 | 采用有依据的分组/时间关系；不套三栏、不带入旧论文方法；最多三级/三档 |
| 混合方法 | 问卷与访谈分别开展、在解释阶段整合的论文，要求中英文 | 两路径并行且在真实整合点汇合；数字/节点/关系一致，分别换行并渲染 |
| 总览与方法展开 | 同一材料分别要求整篇框架和某个创新方法的展开图 | 总览突出研究任务与产物交接；展开图才呈现必要内部操作和控制条件；不把两种粒度混在同一层 |
| 原图融入步骤 | 含输入照片、响应曲线或分区地图，要求配合适当图标 | 图片以输入、处理中间状态、输出或验证角色融入对应环节；不默认旁列原图展示栏；语义合适、来源/许可可查、离线可读 |
| 信息取舍 | 原文同时含关键阈值、多尺度设计与常规模型训练细节，要求研究总览 | 保留设计差异和关键转换；常规实现细节进入配套说明；不用扩大画布和小字容纳全部内容 |
| 图示表达偏好 | 含配对比较、跨期变化或行为类别的材料，要求研究框架但未指定图文比例 | 选用有依据的方法示意、对照结构或动作图标与短标签；解释由图形承担，保留关键条件，不添加材料没有的方法 |
| 示意与实测区分 | 方法已明确但未提供相应结果数值，要求图示解释 | 自绘点线等若有数据图外观，图面标明 Schematic / Conceptual；不把示意斜率、间距、点数写成实际效应、地理距离或样本量；类别图标不缩窄编码定义 |
| 图示化追改 | 要求将指定方法部分与行为类别改成更多图示、更少文字 | 精简授权区域的解释标签、保留比较条件；原照片、数字与研究分支不误改，记录删改并按目标展示宽度检查图形和标签间距 |
| 择优后解释 | 先完成多组合拟合、按范围选优，再分析变量影响或曲线 | 保留选择步骤及后续分析范围，不让选优后的解释看起来适用于全部组合 |
| 整图可读性 | 图内含文字、图片及图例，要求按目标版面使用 | 在记录的目标展示宽度下实际看每个交付语言版本的整图，再看密集局部；原图的必要小字也可读；不以三档字号或无溢出替代此检查 |
| 局部追改 | 接受初稿后要求“只放大中间部分，其余内容不变” | 只修改指定范围和必要连接；授权外文字/数字/边无变化，仍最多三档字 |
| 删除后续改 | 删除一条参数行后再改全图留白 | 删除记录被保留，重新生成未恢复该行 |
| 空框/并行陷阱 | 提供含空白框的草图，原文明确两项分析来自同一模型 | 不补造方法；移除空框或合理重排，两分析从上游分叉 |
| 不完整材料 | 只有摘要或缺少关键结果图 | 明确覆盖范围/缺图；不声称读了全文或制造真实结果图 |
| 原文信息缺口 | 正文和图注命名不一，或缺少一个方法参数 | 标明来源和不明确处，不补造数字；区分资料缺口与制图错误 |

起始测试提示可用：

> 请使用 $paper-roadmap，根据附件论文制作研究框架图。请提炼研究任务与关键输入、处理和输出，将有价值的论文原图融入对应步骤，自行选择布局和配色，最多三级视觉层级，输出可编辑 SVG 和预览。

此提示未指定成图语言，应默认生成英文；另用明确要求中文或双语的请求测试覆盖默认值。

追改提示：

> 以刚才认可版本为基线，只放大中间模块的正文和图标、收紧多余留白。其他文字、数字和研究关系保持不变，仍最多三档字号。

记录文件名、请求、实际输出、检查结果和待修正点即可。失败要保留具体证据（例如哪条箭头、哪段文字、哪张素材）；根据观察做窄范围修改，不把某一论文的特殊步骤写成所有论文的规则。

## 既有材料的回归核对点

材料可用时，可用以下两篇再次制图；未实际重画并查看之前，不把修订后的场景记为通过。这些核对点只属于相应论文，不是其他论文的固定方法或参数。

- Shi et al., *Why same datasets yield different environment–activity relationships?*（DOI: 10.1016/j.compenvurbsys.2025.102398）：轨迹分配与环境范围独立变化；RF 先比较组合，再选最优范围（步行 20 m、骑行 10 m），随后比较分配方法及 PDP。检查摘要压缩后是否仍保留这个选择与范围限定。
- Gao et al., *Precision governance for urban decarbonization*（DOI: 10.1016/j.scs.2026.107573）：客货运核算、SHAP 贡献模式聚类及四区策略关系准确；曲线与地图进入相应解释/输出环节；总览避免堆叠常规训练小字，保留关键的双轨比较与真实选择步骤。

另一次街景研究方案的局部追改中，实际观察到匹配与变化分析仍以文字列表为主、行为类别缺少动作表达。修订后用配对点、两组两期变化示意及行为组合图标替换解释性文字，并核对研究关系、原图和样本数字的保留；完成整图与局部查看。该经验支持本技能的图示表达偏好，不将相应方法、分类、版式或减字幅度设为其他论文的要求。此后规则修订的结构检查不等于重新完成独立盲测。

## 记录与判定范围

2026-10-23 的一次独立前向试用使用了新的农田生物炭研究方案：中文请求未指定语言和风格，三个处理在相同施肥条件下接受三项并列测量，且没有结果数据。实际输出英文可编辑 SVG 和 PNG，完成两轮成图与两张随包参考图的同屏比较，修复分支线穿标题及基因符号不清的问题，并查看最终整图与密集局部。未添加处理排名、效应数值或伪因果路径。该次用 Sharp/librsvg 完成渲染；浏览器检查器因 Chromium 未启动而没有几何检查结果，另有静态检查。它验证了这一方案的默认英文、图解组织与比较流程，不代表已覆盖真实论文原图融合、双语、内容锁定追改或用户编辑器兼容性。

简要区分：自动结构检查、对原文的内容回查、实际视觉查看、用户软件内编辑或连续追改，以及未完成项目。前几项各自通过不自动意味着后几项通过；标签和模型一致不证明原文关键信息没有共同遗漏。

只有新场景实际观察到的问题才登记为失败。两篇城市交通/空间数据论文不能独立证明所有学科、实验或混合方法均已适用；局部修改与删除保持也需单独试用。不要把原文数据复现列为本技能制图测试的默认任务。
