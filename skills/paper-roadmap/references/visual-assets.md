# 视觉设计与素材

默认 Innovation 图解风格和参考选择见 [innovation-style.md](innovation-style.md)。以下原则用于选择当前研究的图形与素材，不把参考图改成固定模板。

## 选择而非套版

先从论文逻辑、图的范围与产物衔接选阅读方向和分组，再决定宽高比例。参考图可以借鉴节奏、图文比例、线条和留白；不能把其箭头关系搬到不同研究。用户没有参考图时自行提出适合当前内容的设计并直接制作。

模块的视觉份量随解释需要分配：关键创新、配对比较和重要产物可以占更大面积，常规步骤可压成短标签。不用等大卡片、等步数、每框一个图标等形式把所有信息等重排列。

保持最多三级视觉层级/三档字号。可用“模块 → 方法节点 → 必要说明”，也可只有两级。阶段编号、图例、图注和边标签纳入现有层级，不暗加第四级。单位和数字不应因缩小而无法阅读。

不设默认配色。下表仅为需要候选时的例子，不能在每次任务中自动套用；主文字保持足够深，照片和图表的语义色优先保留。

| 候选气质 | 可考虑的色系 |
|---|---|
| 克制、技术性 | 灰蓝、蓝灰、雾灰 |
| 自然、环境 | 鼠尾草绿、石色、浅灰 |
| 多路径区分 | 灰紫、灰蓝、冷灰 |

最终颜色应由当前图的背景、图片、分组需求及用户参考决定。检查灰度下仍可辨识；不要仅靠红/绿或色相表示方向与组别。字号和图标尺寸按最终使用尺寸判断，不继承历史实例的 2400 × 2400、48/44/40 或“两档图标”。

初稿拥挤时先检查表达粒度与信息取舍，再调整图形表达、断行、框宽/框高、组间留白、图文位置和画布比例。不要为容纳所有方法细节不断扩大画布；内容锁定后不得擅自改写或删字。不能用无意义空框填满画布。

三档字号只限制样式数量。比较不同画布时，应按相同目标展示宽度检查有效字大小；例如画布从 2400 增至 3200 宽而正文仍为 30，等宽展示时正文会小约 25%。这只是可读性判断的例子，不是新的固定画布或字号要求。原图自带的小字也纳入检查，不能只看可编辑文字是否合规。

## 让图示承担方法与行为表达

默认倾向于“图示解释过程，短标签说明关键含义”。先判断读者需要看懂哪种关系，再选有信息价值的表达；以下是候选，不是固定模板，只有当前材料支持相应方法时才采用。

| 要表达的内容 | 可用图示 | 必须保留的含义 |
|---|---|---|
| 匹配与可比组 | 不同形状的组别点位、配对连线、筛选前后结构 | 配对比例、选择或分层依据及必要平衡条件；区分倾向得分卡尺与地理距离，不能混成一个尺度 |
| 两组跨期变化或 DID | 共用时间轴的组别变化、变化括号或短差值表达 | 真实组别与时间、比较的是何种变化；概念线条不能暗示已估计的结果或已验证的平行趋势 |
| 活动与行为类别 | 可辨认的人物动作或组合图标，配短类别名 | 图标是代表性动作，不能把原类别缩窄；例如穿行若含步行和骑行，应兼顾二者或用中性移动表达 |
| 多类输入或协变量 | 按有依据的类别组织图标、矩阵或小组 | 变量组的覆盖范围；图标组数不等于实际变量数，完整定义留在内容记录或正文 |

方法名、组别、单位、时间和决定设计的条件可保留。常规参数、完整变量表和重复解释移入正文或配套记录。减少文字的判断标准是图意更清楚且科学含义完整；不设统一减字比例、每框字数或图标数量。

区分真实证据与自绘方法示意：有来源的样本、地图或结果图沿用其真实数值与比较条件；没有实测值也可用点、线和关系解释方法。后者若具有数据图的外观，图面需标明 `Schematic` / `Conceptual`，在内容记录中说明点数、斜率、距离等不编码实测结果。示意布局不能冒充实际地理位置、效应大小或样本数量。

用户要求“减少文字、改用图示”时，可精简其授权区域的解释性标签，保留必要比较条件并记录删改。若同时要求特定文字或研究关系不变，图示替换仍须遵守相应锁定范围。

## 图标决策与实际搜索

1. 明确图标要表达的是对象、动作、测量、算法还是结果；不需要图标的节点只保留文字。
2. 检查本任务和技能已有素材。少量通用图标在 `assets/icons/`，来源见 `sources.json`；它们不是固定图标列表。
3. 缺少合适图标时，按概念搜索官方库，例如 Tabler、Lucide、Iconoir。结合英文名与近义词；优先同一套 outline SVG。打开具体图标及许可页，再保存所用 SVG。
4. 核对图标语义、线宽、端点、视觉重量和实际尺寸。把 SVG 路径嵌入主图，重命名内部 ID 以避免渐变/裁切 ID 冲突。保留可编辑矢量，不用低清截图代替。
5. 素材来源表记录具体文件、原始 URL、库/作者、许可及许可 URL、获取日期、修改方式和使用节点；保留许可要求的声明。

官方入口（使用时核对当前页面与许可）：

- Tabler: https://github.com/tabler/tabler-icons
- Lucide: https://github.com/lucide-icons/lucide
- Iconoir: https://github.com/iconoir-icons/iconoir

网络不可用时说明搜索未完成；可使用已知来源的本地素材或文字继续制图。不要自动安装庞大图标包或新增账户。

语义判断例子：

- 活动/行为是人物或动作；活动规模/统计量才适合统计图。
- 聚类地图要同时体现地理位置和分组；泛用地图图标不一定足以表达聚类。
- 多个算法需要区分，但不能为“看起来不同”而暗示未实施的模型机制。可用同风格的概念组合加准确名称。
- 文字对比可用词云形式作中性符号，但词云中的真实词和频率属于数据；无来源时不编造看似研究发现的词。
- 真实品牌 logo 仅在品牌身份确有意义时使用；不能用自画标志假冒官方 logo。

没有精确图标时，可以组合已核对许可的简单几何/图标，记录派生来源；表达不了就用文字。每个框都有图标并不是目标。

## 使用论文图片

判断这张图是否提供图标无法替代的信息：研究对象、仪器装置、材料形态、案例环境、空间格局或关键结果。若只是装饰，通常不放。

- 先明确图片在当前图中的角色：输入样本、处理中间状态、关键输出或验证对照，并对应到具体步骤。研究区可进入对象/数据模块，响应曲线可进入解释环节，分区地图可作为聚类输出；不默认把所有原图移到流程旁的独立展示栏。
- 让图片与短标签共同完成步骤表达，可在模块内部或紧密相接的展开区组织“输入 → 关键转换 → 输出”。若专门比较多组结果确需独立面板，应让其与相关步骤的对应明确；不为了把图片接上而伪造数据流箭头。
- 同一场景或对象的前后对照保持可比的裁切、尺度、视角和标签；标明实测、模拟、预测等身份。完整提示词通常留在说明中，方法展开图只保留理解控制条件所需的约束。
- 从原文件提取图片或高质量页面裁片。保留原件，另存裁片；来源记到章节/图号/面板和裁切范围。截图仅在无法获得更好源时使用并说明清晰度限制。
- 结果图不改变数据、坐标或比较条件，不删除理解所必需的图例、单位和比例尺。多面板可只选相关面板，但不能造成结论误读。
- 标注、去掉无关页边或一致裁切可以进行；不生成“更漂亮”的实验结果、地图、病例照片或街景替代原图。
- 将图像嵌入 SVG 为 data URI，记录对应原文件。保持比例；除用户要求外不拉伸，也不裁掉关键信息。检查最终展示尺寸下的字和细节。
- 缺少需要的原图时先保留文字或中性图片符号并标明待补；不能称已嵌入或已核对论文原图。
- 用户要求纯矢量但原图是照片时，说明照片将嵌入为位图，其他元素可编辑；不擅自描摹成伪数据图。

整图缩览时若原图的必要内容难以辨认，优先选取保留完整语义的相关面板、扩大关键局部或减少重复文字，再重排模块。不能只以“原图完整”“放大可读”判定图面合格。图例、单位和比较条件不能为获得更紧凑的裁片而被删除。

图片和第三方标志的权利沿用原来源。来源记录用于追溯，不自动等于取得公开再分发许可。用户为某个任务提供的个人参考图，其照片和 logo 不自动成为通用复用素材；公开分享前应核对相应权限。
