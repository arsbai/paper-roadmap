# Paper Roadmap

[English](README.en.md) · 中文

一个面向 Codex 的科学论文制图技能：从论文、研究方案或方法材料中提炼研究逻辑，生成**默认英文、可编辑的 SVG 技术路线图、研究框架图或方法流程图**，并交付 PNG 预览。

默认风格接近 **The Innovation / The Innovation Geoscience**：用浅色任务分区、清晰标题带、对象与方法图解、真实论文图及短标签组织研究。布局仍由研究关系决定，用户指定的风格优先。新图和整体重绘在交付前完成两轮成图与参考图的实际视觉对比和优化。

## 适合做什么

- 从全文梳理输入、关键处理、输出及真实依赖关系，区分串联、并行、分组、验证与解释性综合。
- 把有价值的论文原图融入对应步骤，例如输入样本、方法中间状态、解释曲线、分区地图和验证对照。
- 优先用方法示意、对照结构和行为图标承担解释，文字保留方法名、类别名和关键条件；不设固定图文比例。
- 精简总览中的常规实现细节，保留关键筛选、择优、分组、尺度选择及创新；最多三级视觉层级、三档字号。
- 根据研究关系选择布局、画布和配色；不固定三栏，也不要求每个框都有图标。
- 随包提供 10 张带来源和独立许可的 Innovation 参考图；按当前任务选择相关图例，学习表达方式而不复制研究内容。
- 按认可版本做局部修改，记录已删除内容，支持明确指定的中文或中英双语版本。

它是制图工作流，不执行论文的数据分析，也不生成冒充真实研究结果的图表。

## 安装

在支持技能的 Codex 环境中发送：

```text
请使用 $skill-installer，从以下地址安装 paper-roadmap 技能：
https://github.com/arsbai/paper-roadmap/tree/main/skills/paper-roadmap
```

安装器不可用时，下载本仓库，将完整的 `skills/paper-roadmap` 文件夹放入当前环境的技能目录。按[官方技能文档](https://developers.openai.com/codex/skills/)，个人技能目录为 `~/.agents/skills/`，项目内为 `.agents/skills/`。部分安装器使用 `$CODEX_HOME/skills`，默认为 `~/.codex/skills`；以实际安装器返回的位置为准，避免在多个目录重复安装同名技能。

最终结构应为 `<技能目录>/paper-roadmap/SKILL.md`，同时保留 `agents/`、`references/`、`scripts/`、`assets/` 和许可文件。不要只复制 `SKILL.md`。技能未显示时，新开会话或重启 Codex。

## 第一次使用

附上可读取的论文 PDF；可选补充用途、目标尺寸、重点和风格参考，然后发送：

```text
请使用 $paper-roadmap，根据附件论文制作整篇研究框架图。
提炼关键输入、处理和输出，把有价值的论文原图融入对应步骤。
方法与行为类别优先用图示配短标签，只保留关键文字；自绘方法示意标明 Schematic。
自行选择布局和配色，最多三级视觉层级，输出可编辑 SVG 和 PNG 预览。
默认采用接近 The Innovation 的图解风格，完成两轮与参考图的视觉对比和优化。
```

**未指定成图语言时只生成英文版。** 中文交流或中文材料不会切换默认语言。需要其他语言时明确写出“生成中文版”或“同时生成中英文对应版本”。修改内容锁定的已有图时，会保留该图语言，除非明确要求切换。

也可以限定范围：

```text
请使用 $paper-roadmap，只画 Methods 2.3 的方法展开图。
突出输入、关键转换和验证对照，生成英文版，适合论文双栏通栏宽度。
```

## 继续修改

保留上次交付的 SVG、内容记录和素材目录，在同一会话中继续；换会话时一并提供：

```text
以刚才认可版本为基线，只放大中间模块的正文和图标。
其他文字、数字、研究关系和图片保持不变，仍最多三档字号。
```

减少文字、增加图示的例子：

```text
把方法部分改成图示配短标签。若原文包含匹配或 DID，分别用配对点和两组跨期变化示意；
行为类别配对应动作图标。保留比较条件、关键阈值及研究关系，常规参数移到配套说明。
自绘方法示意标注 Schematic，真实照片与结果数据保持原意。
```

类别图标表示代表性动作，不能代替完整定义或改变类别范围；方法示意中的点数、斜率和间距也不代表论文的实际结果。

删除后继续调整的例子：

```text
删除“常规参数设置”这一行，记录为已删除；其他内容不变。
```

```text
在上一版基础上收紧留白，保持已删除内容不恢复。
```

## 交付内容

| 文件 | 用途 |
|---|---|
| `paper-roadmap-en.svg` | 默认英文成图；文字、连接和图标保留可编辑元素，论文照片可嵌入为位图 |
| `paper-roadmap-en.png` | 渲染预览，用于实际查看整图和密集局部 |
| `diagram-model.json` | 节点、关系、证据位置、素材角色、开放问题及删改状态，按任务裁减 |
| 素材与来源记录 | 追溯论文图号、裁切、图标来源和许可 |
| 检查记录 | 区分自动检查、原文回查、实际视觉查看和未完成项目 |
| 两轮视觉对比记录 | 实际查看的参考图、初稿与修订稿、展示宽度、发现和落实的修改 |

文件名可按任务调整；指定中文或双语时交付对应版本。需要 PDF、PPTX 等格式时另行提出。SVG 的浏览器渲染通过不等于已在所有排版软件内测试；字体和编辑器可能影响显示。

## 运行环境与渲染检查

制图需要能读取材料、编写文件和查看图片的 Codex 环境。搜索新图标需要网络；已有素材合适时可复用并保留来源。技能不依赖专用绘图库或 ImageGen。

随附的检查脚本需要 **Node.js、Playwright 包和可启动的 Chromium 浏览器**。宿主有依赖加载工具时优先使用宿主运行时；其他环境参见 [Playwright Library](https://playwright.dev/docs/library)。脚本本身不会自动安装依赖或下载浏览器。

从仓库根目录运行（各命令写在同一行，路径含空格时加引号）：

```text
node skills/paper-roadmap/scripts/render_check.mjs drawing.svg --png preview.png --report qa.json --modules /absolute/path/to/node_modules --browser /absolute/path/to/chromium
```

`--modules` 用于指定已有的 Playwright 包目录；默认解析可找到包时可省略。`--browser` 在 Playwright 能找到浏览器时可省略。可用 `--help` 查看参数。内容锁定修改可增加 `--baseline approved.svg --lock-text`；检查忽略 Unicode 空白，不能单独证明词间空格或科学关系不变。

自动检查发现字号、边界及部分文字问题，**不判断科学正确性、图文融合或展示尺寸下的可读性**；每个交付语言版本仍需实际看图。缺少渲染条件时应明确“尚未完成视觉核验”。

## 测试范围

技能经过两篇城市空间与交通研究论文的本地制图试用，修订了图片与步骤分离、总览小字过多，以及压缩后丢失关键选择步骤等问题。第二篇修订图补齐了英文版，并完成自动检查、原文回查和整图/局部视觉查看。

另用一份街景研究方案完成局部追改，将文字较多的匹配和变化分析改为方法示意，并为活动类别加入动作图标。研究关系、真实照片及样本数字经核对保留，完成整图与局部查看。这次反馈形成了“图示承担解释、文字保留关键”的默认偏好；规则更新后未另做独立盲测。

这些试用不构成所有学科或编辑软件的兼容性证明。跨学科、连续局部修改和删除状态保持仍应在实际任务中验证；默认英文规则的配置已核对，尚未进行独立盲测。回归场景见 [local-testing.md](skills/paper-roadmap/references/local-testing.md)。公开仓库不附论文全文或个人测试成图。
